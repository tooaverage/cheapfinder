One bookmark, works in mobile Safari, mobile Chrome and any desktop browser. On a product page, tap the bookmark → the CheapFinder panel appears with drop-ship signals and price-search shortcuts. Tap again to dismiss.

iPhone / Android

  1. Tap the button below to copy the code.
  2. Bookmark any page (Share → Add Bookmark) and name it CheapFinder.
  3. Edit that bookmark and replace its URL by pasting the copied code.
  4. On a product page: open bookmarks, tap CheapFinder.

Tip: if you use Chrome sync or iCloud, install once on desktop and the bookmark syncs to your phone automatically.
